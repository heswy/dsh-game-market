# v1.5.3 · 保存提示移到会话标题栏

日期：2026-11-01。版本 / tag：`1.5.3` / `v1.5.3`。补丁版本，调整 v1.5.2 保存提示的位置与语言适配。

## 变更

- 保存提示从输入框上方移到**会话标题栏右侧的工具区**（`conversation.session.header.utilities`），作为紧凑 chip：状态点 + `已保存 / 本局暂无新进度` + `继续游戏` + 关闭，8 秒自动消失。
- 文案改由宿主词典解析（`ctx.locale.bind`），中文宿主显示中文、英文宿主显示英文，不再跟随系统 `navigator.language` 误判。
- 行为不变：`继续游戏` 一键恢复该局并打开运行页；真实保存失败仍是弹窗（留在游戏 / 重试保存 / 不保存，离开）。
