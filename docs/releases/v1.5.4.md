# v1.5.4 · 目录索引镜像降级与离线状态收进设置

日期：2026-11-01。版本 / tag：`1.5.4` / `v1.5.4`。补丁版本，修复官方目录索引在部分网络下间歇不可达导致的“离线模式”提示。

## 变更

- **索引镜像降级**：官方 v2/v1 索引按顺序尝试 `raw.githubusercontent.com` → jsDelivr CDN → GitHub Contents API（`application/vnd.github.raw`）。任一成功即正常刷新，不再因为主域名被间歇阻断就进入离线态。缓存身份仍以主 URL 为准，切换镜像不会分裂缓存。
- **离线状态收进设置**：“市场 / 我的游戏”不再显示顶部离线条幅，页头也不再挂离线圆点；在线/离线、状态说明（使用缓存 / 缓存已过期 / 内置目录 / 尚未同步）与上次同步时间只在“设置 → 游戏目录”展示，刷新按钮保留在该处。
- 目录加载失败、空目录的提示保持不变；真实错误仍就地显示并可重试。

## 验证

- 全量 `node --test`：**1579/1579**；`node scripts/check.mjs`：`CHECK OK (45 checks)`。
- 新增 Host 回归：主索引域名不可达时自动改用镜像，并把快照仍写入主 URL 的缓存；镜像全部失败时保持原有离线回退语义。

## 边界

- 镜像端点由内容仓库的公开地址推导（jsDelivr 与 GitHub API），不在本地缓存内容；GitHub API 未认证请求有速率限制，正常 6 小时刷新与手动重试不会触顶。
- 离线期间仍按缓存策略展示上次同步目录；缓存过期（14 天）后只显示本机已安装/内置游戏。
