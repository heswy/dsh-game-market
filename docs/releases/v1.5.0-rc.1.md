# V1.5.0-rc.1 验收候选

本候选用于 M5 验收，尚未正式发布。没有生产 tag、GitHub Release 或 stable 更新索引推广。

## 包与身份

- 安装目标 R：`07f2ef1de6aea2b3857bc7e2983f7f083db7eb99`。
- Client 构建身份 P：`0ca0aacc4501f313776f4ea1e0683255cb14e62b`。
- 原生插件管理器的精确 Git 安装 spec：`https://github.com/heswy/dsh-game-market.git#07f2ef1de6aea2b3857bc7e2983f7f083db7eb99`。
- 当前实测支持：DeepSeek Harness Desktop `0.2.1-rc.3`。不得根据上游 master 接口推断已安装宿主的能力。

固定 R 与构建 P 用途不同：R 标识带完整发行元数据和产物的安装提交，Host 报告实际安装目标 R，Client 报告嵌入的源码构建身份 P；发行元数据建立二者的对应关系。不可要求两个 SHA 相同，也不能仅凭 package.json 版本确认运行已更新。

## 主要内容

- 多文件 ZIP 游戏包、独立资源服务、两代内容目录与旧 HTML 兼容。
- 内置 Orbit Courier；双格式开发者工具、模板、模拟器和投稿校验。
- 固定索引发现更新、保存协调、DSH 管理器精确安装、待重启/激活确认、真实 Host/Client 身份核对。
- HTML wrapper 与真实 `dsh-app://app` 桌面来源支持。
- 小鲸鱼四态、气泡和游戏内普通问答；危险工具审批与不支持的问答模式回 DSH 原生会话处理。
- 受控游戏进度导出、导入及覆盖前备份；校验 gameId、schema、大小、SHA-256 校验和和 revision。没有账号或云同步。

## 更新与恢复

参见 [恢复指南](./v1.5.0-recovery.md)。不先卸载插件、不手动覆盖包、不复制账号资料。rc 候选仅用于明确选择测试通道的隔离环境，stable 用户不会自动收到 prerelease。
