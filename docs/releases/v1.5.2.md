# v1.5.2 · 保存提示柔和化

日期：2026-11-01。版本 / tag：`1.5.2` / `v1.5.2`。补丁版本，只调整保存提示与离开流程。

## 修复

- **“暂时无法保存”误报**：游戏在菜单/未开局界面被暂停时会主动不写存档（`shouldPersistRun` 为假），宿主等不到 `storage.save`，6 秒超时后把“无需保存”当成写失败并弹出红色对话框。运行时的暂停结果现在携带 `skipped`，Client 将其判定为“没有新进度”而不是失败，不再弹窗。
- **离开后的轻提示**：从游戏返回会话（含右下角鲸鱼“返回工作”）后，在输入区上方显示一条可自动消失的提示：
  - 真正写入成功：`已保存`；
  - 游戏没有新进度：`本局暂无新进度`；
  - 两者都带 `继续游戏`，一键回到该游戏并恢复；8 秒后自动消失。
- **真实失败仍提示**：写入确实失败（存储错误、桥无响应）时保留对话框，但标题改为 `进度未保存`，按钮层级改为 留在游戏 / 重试保存 / 不保存，离开，红色危险按钮不再是主操作。

## 兼容与安装

- 支持 DeepSeek Harness `>=0.2.0 <0.3.0`；DSH `0.2.1-rc.3` 与 `0.2.1-rc.5` 均已覆盖。
- 已安装 v1.5.1 的用户：设置页检查更新，或在原生插件管理器用精确 commit 安装本次 R。

## 验证

- `node --test`：**1578/1578**（新增：暂停“未发起保存”透传、离开结果分类、提示状态）；`node scripts/check.mjs`：`CHECK OK (45 checks)`。

## 边界

- 判定依据是“游戏是否发起 storage.save”。菜单/无进度游戏的静默跳过按成功处理；桥真正无响应仍走失败提示。
- `已保存` 提示显示在会话输入区上方，离开到市场页时不显示。
