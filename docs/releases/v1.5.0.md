## 交付

- **多文件资源包（asset-zip-v2）**：ZIP 包树、两代目录双投影、独立资源 origin 与 CSP/wrapper，旧 HTML 包保持兼容；投稿、审核、发布、更新、撤下链路接通。
- **新内置游戏 `orbit-courier`**：外链 ESM/CSS/图片/音频/关卡的多文件包，约 120 秒三航段，键盘可玩，暂停/静音/最高分/自动存档与 Continue。
- **平台持续更新**：发现固定索引 → 用户确认 → 保存与运行冻结 → DSH 管理器精确 Git commit 安装 → Host/Client 双端身份核验；失败、待重启、旧 Client 等状态可见且有恢复入口。
- **游戏内原地问答**：普通问题、计划审阅与危险审批留在原生 seam，不伪报批准，草稿不进入存档。
- **存档可移植**：导出仅含游戏标识、版本、schema、键值与 SHA-256；导入校验 gameId/schema/配额/校验和，覆盖前先备份，并与卸载删除数据互斥。
- **外部分发工具**：双格式 CLI、Vanilla/React 模板、`dsh-game-developer` Skill、GitHub 内容仓库模板与维护者上架工具。
- **前端改版**：首页/详情按封面色调延展，My Games 增加继续主卡与最近游玩架，封面按分类生成构图，新增设置面板集中目录刷新与更新状态；修正“最高分”标签。
