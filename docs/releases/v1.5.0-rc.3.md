## 与 rc.1 的差异

- 修复 M5 复核复现的三项存档迁移阻塞：导入与 `deleteData` 卸载双向互斥；`meta.json` 写失败降级为成功并返回 `warnings: ['save-meta-write-failed']`；导出、文件门禁、请求体与 `/save-import` 统一使用共享传输预算。
- 导出的进度文件改为紧凑 JSON，保证合法近配额存档可导出且不超过导入界限。
- 无新增游戏；存档导入接口仅增加部分成功 warning 与传输预算，不改变游戏 SDK 契约。
