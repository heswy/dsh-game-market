# v1.5.6 · 首发游戏全部内置

日期：2026-11-02。版本 / tag：`1.5.6` / `v1.5.6`。补丁版本，只改内置游戏清单与内置目录探测，不动运行时包格式、Registry 协议、存档与更新状态机。

## 变更

- **2048 / Breakout / Jump 改为内置**：三款游戏随插件打包，安装后即在「我的游戏」中可玩，不再依赖社区目录或 seed 下载；`snake` 与 `orbit-courier` 保持原样。
- **全新安装的游戏清单**：5 款内置（`snake`、`2048`、`breakout`、`jump`、`orbit-courier`）+ 社区目录中的可下载游戏（当前为 `little-leviathan`）。
- **内置目录缺失时的行为**：html-v1 内置游戏的目录不存在时直接跳过，不再生成无法游玩的占位条目；目录存在但内容损坏时仍保留诊断（与既有 broken-builtin 行为一致）。
- **安装耗时不变**：三款游戏目录原本已在插件包 `files` 内，本次只登记为 builtin，不新增随包文件，也不增加下载/复制/解压步骤。
- 注入 `games/2048` 之外无新增资产；`registry/` seed 保持不变，旧客户端仍可回退使用。

## 验证

- 新增回归测试：全新安装列出 5 款内置游戏，均 `installed`、`builtin`、入口可用；`/installed` 与 `/health builtinCount` 一致。
- 全量 `node --test`：**1580 例，1575 通过、4 跳过、1 环境相关失败**（`/health buildCommit` 读到本机已安装插件的固定 commit，与本次改动无关；干净 CI 环境为 0 fail）。
- `node scripts/check.mjs`：`CHECK OK (45 checks)`。
