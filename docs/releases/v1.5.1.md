## 修复

- **会话 Game 标签消失 / 会话标题栏整体不渲染**：rc.5 的 View 标签行会逐字符估算标签宽度（`for (const glyph of label)`），非字符串会抛错。v1.5.0 把 React 状态徽标作为 `conversation.view` 的 label 传给了宿主，导致整个会话标题栏（面包屑、标题、标签行）在该版本下不渲染——用户侧表现为“session 上面没有 bar 了、游戏没有入口”。
- 现在标签 label 为纯字符串（`游戏` / `Game`），由宿主在语言切换时重新解析；rc.3 与 rc.5 均正常显示 Chat / 游戏两个标签。
- 标签上的状态徽标随自定义 label 一并移除；运行页内的 Agent Presence 鲸鱼与市场/恢复行为不变。

## 兼容与安装

- 支持 DeepSeek Harness `>=0.2.0 <0.3.0`。
- 已安装 v1.5.0 的用户：设置页检查更新，或在原生插件管理器用精确 commit 安装本次 R。
- 行为不变：首次进入游戏标签打开市场；本会话玩过游戏后再次进入会直接恢复该游戏。
